## 👾 matrix.nullstar.fun

### running locally

<br>

start the local development server at **[`localhost:8088`](http://localhost:8088)**:

<br>

```bash
make install
make server
```

<br>

### development

<br>

```bash
make pre-commit
make lint
make test
```
